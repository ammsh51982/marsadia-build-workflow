# Decisions

One file per owner decision, named `OD-<slice>-NN-short-name.md`, plus architecture decisions named
`ADR-NNN-short-name.md`. Start from `_TEMPLATE.md`.

A decision is recorded with the owner's own words and the time he gave them. A record is never
edited to change a decision: a later decision is a new record that names the one it amends.
